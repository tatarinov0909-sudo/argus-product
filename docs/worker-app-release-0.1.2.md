# Приложение грузчика 0.1.2 — исправления аудита, 09.10.2026

Исправлены все шесть воспроизведённых клиентских дефектов независимого тестера.
Выпуск опубликован на сайте; Android обновляется поверх 0.1.1 прежним ключом.

## Исправления

| Проверка | Поведение после исправления |
| --- | --- |
| F01: потеря ошибки загрузки заданий | Ошибка остаётся на главном экране с кнопкой «Повторить». Неизвестное количество не превращается в ноль; ранее загруженные данные явно помечаются. Повтор показывает загрузку. |
| F02: недоступные с клавиатуры плитки | Все шесть плиток и выход — настоящие кнопки с видимым фокусом, доступны через Tab, Enter и Space. |
| F03: обрезанный длинный номер прихода | Номер переносится целиком, включая допустимый номер из 44 цифр на мобильном экране. |
| F04: поздний ответ открывает старое задание | Ответ, пришедший после «Назад» или выбора другого документа, не меняет экран, текущий документ и таймер. |
| F05: фильтры скрывают приходы | Фильтры и список находятся в одной прокручиваемой области; до документов можно дойти даже при 120 продавцах. Фокус выбранного фильтра сохраняется. |
| F06: бесконечное сканирование при отказе BarcodeDetector | После ошибки включается jsQR. Отказ резервного распознавания показывает ошибку и повтор; камера останавливается. Загрузка ограничена 10 секундами, поздние результаты закрытого сканера игнорируются. |

При подготовке обнаружено уже опубликованное исправление общего `auth.js`:
старый или истёкший вход не должен заменять новую сессию. Его текущая публичная
версия перенесена в исходники и APK; публичный `auth.js` не перезаписывался.
В страницах грузчика обновлена ссылка для сброса старого браузерного кеша.
