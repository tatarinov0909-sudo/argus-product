## Решения, принятые по ходу (владельцу стоит знать)

- **Жёлтый цвет у заказа** учитывает и поставки, которые уже собираются:
  5 шт. на полке, 5 ждёт собираемая поставка, ещё 3 в новых заказах —
  жёлтый («нужно 3 + 5 в поставках»).
- **Чужую сборку можно забрать** («▶ Забрать сборку себе», с подтверждением):
  иначе поставка, брошенная с разряженным телефоном, висела бы «собирает
  Дима» навсегда. В журнале видно, кто у кого забрал.
- **Выход по скрытой вкладке — через 15 секунд**, чтобы короткий взгляд в
  уведомление не ставил паузу. Записано в `docs/Отложено.md` — проверить на
  живом складе.
- **Бумажный лист без QR** — ссылкой «Собираю по бумажному листу — начать
  без скана QR» под двумя кнопками, через то же окно «Начать».
- **На телефоне экран грузчика — во всю ширину** (рамка с полями по 24 px
  убрана до 480 px).
