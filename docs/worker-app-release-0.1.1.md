# Обновление приложения грузчика 0.1.1 — 08.10.2026

## Что исправлено

- На странице установки iPhone и браузер ведут в `worker-login.html` — отдельный
  вход грузчика. Повторное открытие с действующей сессией сразу открывает работу.
  Manifest значка запускает этот же вход. Общая страница кабинетов сохранена.
- Сессия работника действует 30 дней и продлевается во время использования.
  Действующие старые короткие токены обновляются при следующем запросе.
  Истёкшие токены не оживают; отзыв ключа и смена роли проверяются сервером
  до продления. Правила остальных ролей и интеграций не изменены.
- На устройстве сохраняется токен, исходный ключ работника не сохраняется.
  При запрете хранилища показывается ошибка вместо цикла переходов. Выход
  удаляет только вход работника. Вход Safari и значка на главном экране может
  потребовать отдельной первой авторизации; секреты через URL не передаются.
- Камера скрыта до первого видеокадра; системная кнопка Play не показывается
  во время запуска. Есть состояния ожидания, отказа разрешения, ошибки запуска,
  отсутствия кадров и повторного включения. Закрытие/уход со страницы выключают
  камеру; поздний ответ на запрос разрешения не включает закрытый сканер.
  Заголовки QR ячейки и листа сборки различаются.

## Проверки

- API: 6 тестов срока/продления/отзыва/подделки токена, 19 auth-hardening и
  37 manager-role — PASS. Проверки записи только на отдельной локальной БД;
  внешние запросы в интеграционных тестах заблокированы.
- Клиент: Chrome 26/26 (runtime, native bridge, web auth), WebKit 4/4 для входа.
  Реальный перезапуск постоянного браузерного профиля сохраняет вход.
- Сканер в Chromium и WebKit: 375/390/768/1440 CSS px и горизонтальный экран
  844×390; разрешение/отказ, повтор, отсутствие кадров, ошибка play, поздний
  getUserMedia, завершение видеотрека, pagehide. Проверки используют подмену камеры.
- Вход и страница установки: 375/390/659/660/661/768/1440 CSS px, состояния
  загрузки и ошибки, инструкция iPhone, отсутствие переполнения.
- Android-эмулятор: реальные кадры камеры 480×640, отказ → повтор → разрешение,
  закрытие/повторное открытие, аппаратная «Назад» на главном экране и поверх
  активного задания. Камера останавливается; задание остаётся открытым.
- Подписанный release установлен через `adb install -r` поверх установленного
  0.1.0 без удаления приложения/очистки данных. VersionCode изменился 1 → 2,
  firstInstallTime сохранён. Экран входа работает, DEBUGGABLE и WebView debug
  socket отсутствуют, crash log пуст. Это не проверка Play Protect.

Физический iPhone и ТСД владельца в этих проверках не участвовали.

антивирусов не заменяют решение Play Protect на устройстве. Завершённый
