## Что нашли на рабочем складе 27.09

Продавец оформил привоз ПР-270926-1, руководитель отметил «машина приехала»,
а грузчик «не увидел» его в «Приёмке товара». Он там был, но 167-м: открытых
приходов 167 — 126 старых приходов из 1С (никто их через Аргус не принимал),
40 «заказов поставщику» из 1С (`source_document_type = 'supplier_order'`,
это ещё не привоз), 1 привоз продавца. Список в `loader.html` (`openDocs`)
идёт от старых к новым, без поиска и фильтров.

## Что сделать

### A. Грузчик — «Приёмка товара» (`loader.html`, `openDocs`, приёмка)

1. **Порядок списка:** сверху — «машина приехала, принять» (по времени
   приезда), затем «привезут сегодня» (по окну), затем остальные привозы
   продавцов, затем приходы из 1С. Внутри — новые выше старых.
2. **Поиск и фильтры:** поиск по номеру, продавцу, перевозчику, машине;
   фильтр «Продавец», «Статус» (ждёт машину / приехала / принимается),
   «Откуда» (от продавца / из 1С). «Заказы поставщику» из 1С — по умолчанию
   скрыты (см. вопрос 3).
3. **«Машина приехала»** (отметил руководитель, менеджер или грузчик) —
   привоз заметно выделен у всех грузчиков: «Приехала в 10:40 — принять».
4. **Всё, что сделано для сборки в первом задании, — и здесь**, где
   применимо: подтверждение старта «Сейчас запустится таймер приёмки»,
   пауза при выходе с записью руководителю, «Продолжить / Закончить /
   Отказаться», комментарий «где оставил, что осталось», строка состояния
   «На паузе · Джоник · принято 3 из 8», крупно штрихкод / артикул /
   артикул WB, компактное поле количества одной строкой с названием, номер
   прихода один раз по центру, без имени грузчика в шапке, без
   моноширинного шрифта. Сервер — по тому же образцу, что состояние сборки
   из первого задания (переиспользовать, не дублировать).
5. **Выбор места для товара:** «Ввести ячейку вручную» — **самым первым**,
   выше подсказанных ячеек (сейчас — модалка «своё место» внизу).

### B. Кабинет склада — «Приход товара» (`cabinet_main.js`, `renderReceiptsList`, карточка `renderReceipt`)

6. **Поиск** по номеру, продавцу, перевозчику, машине, номеру документа
   поставщика.
7. **Фильтры:** продавец, статус (ждёт машину / приехала / принимается /
   принят / есть расхождение / продавец не согласен), откуда (от продавца /
   из 1С / вручную), период. Сортировка: новые выше.
8. **Оформление:** ровные отступы, выравнивание столбцов, без
   моноширинного шрифта (сейчас `staff-key`, `rc-src` — mono и кривые
   отступы). Список не должен тонуть в 167 старых приходах — те же правила
   порядка, что у грузчика, и «Показать ещё».

### C. Привоз у продавца (`seller-cabinet.js`, `openInbound`)

9. **«Окно выгрузки» переименовать** — по смыслу «время у ворот / рампы
   склада» (вариант выбирает владелец, вопрос 1).
10. **Клавиатура:** в форме «Привезти товар» (и во всех формах кабинетов)
    стрелки ↑/↓ и Enter переходят между полями, как Tab; Enter в последнем
    поле не отправляет форму случайно. Поля даты и времени — стрелки
    работают как у браузера внутри поля, между полями — Enter/Tab (см.
    вопрос 2).

### D. Схема склада и адрес ячейки

11. **Нажал на ячейку на схеме** (кабинет склада «Склад и ячейки»; у
    грузчика — везде, где видна ячейка) — **полная информация** о том, что
    в ней лежит: товар, продавец, артикул, штрихкод, артикул WB, количество,
    годное/брак, когда положили. Сейчас — только часть.
12. **Адрес ячейки — `ряд.стеллаж.ярус`** (рисунок владельца 27.09:
    по горизонтали стеллажи 1, 2, 3…, по вертикали ярусы 1…6, ячейка — их
    пересечение; «1.7.3» — ряд 1, стеллаж 7, ярус 3). Сейчас Аргус пишет
    `ряд.ярус.ячейка` (`argus-api/src/cells/label.js`, решение 24.09) —
    то есть та же ячейка сегодня подписана «1.3.7». **Делать только после
    ответа на вопрос 4.** Если «да» — поменять порядок в одном месте
    (`formatBlockLabel`) и везде, где адрес разбирается обратно: загрузка
    остатков по ячейкам (`src/cells/initialStock.js`, бланк), поиск
    Кладовщика по адресу (`parseCellAddress` в `src/agents/kladovshchik.js`),
    подписи на схеме (`blockAddr` в `cabinet_main.js`), грузчик, печатные
    листы, промпт Кладовщика (`orchestratorPrompt.js`: «ряд.ярус.ячейка»).
    Тесты, где зашит формат адреса, — поправить.

## Вопросы владельцу (задать до начала работы)

   водителю и продавцу.)

4. Адрес «ряд.стеллаж.ярус» вместо нынешнего «ряд.ярус.ячейка»: подтвердите,
