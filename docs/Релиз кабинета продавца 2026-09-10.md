# Первый этап кабинета продавца — 10 сентября 2026

Опубликован на https://argus-ai.online/client_access.html.

## Реализовано

- Остаток открывается первым, независимо от наличия актов приёмки.
- Полноширинная таблица, три итоговых числа, поиск и фильтр нехватки.
- Сверка с 1С сохраняет известный ноль и показывает расхождения по товарам,
  даже если их суммарные отклонения взаимно погашаются.
- На складе = годное в ячейках + фактически подобранное для ещё не
  отгруженных заказов. Подбор больше не вычитает товар повторно.
- 1С служит только для сверки; её остаток не заменяет остаток Аргуса.
- Карточка последних операций товара и категории негодного товара.
- Excel выгружает текущий экран; поиск и фильтр остатков учитываются.
- «Уехало» включает только заказы со статусом shipped. Время пока подписано
  как время сборки, поскольку дата фактического отъезда в контракте отсутствует.
- Убраны неверное указание ИИ как исполнителя приёмки и показ ключа в акте.

Учёт собранного в этом релизе вычисляется по существующим shipping_records.
Новая физическая зона склада, миграции базы и изменения модуля 1С не вводились.
Доступное считается по SKU с ограничением нулём; дефицит выделяется отдельно.
Резервы 1С не добавляются поверх количества заказов.

  SKU у двух продавцов. Выполняется только на базе с тестовым именем.

- Браузер: 1440×1000 и 390×844; поиск, нехватка, история, экранирование текста,

## Границы релиза

Отдельный экран заказов, регистрация с email, доставка уведомлений, файл
импорта в 1С и полная история с пагинацией ещё не реализованы. История
показывает последние 200 записанных операций и явно предупреждает об усечении.
Проверка изоляции выполнена на тестовых данных; корректность назначения всех
живых товаров реальным продавцам этим не подтверждается.

Резервные копии перед публикацией сохранены: фронтенд в work/ этой задачи,
модуль API — в отдельной тестовой папке сервера. Секреты в репозиторий не внесены.
