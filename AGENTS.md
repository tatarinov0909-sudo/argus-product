# Argus — инструкции для Codex

Прочитай `CLAUDE.md`, `.business/`, `rules/` и текущий файл из `plans/` перед
изменением продукта. Этот файл дополняет, а не заменяет их.

Работай маленькими проверяемыми этапами. Перед изменением сверяй фактическое
состояние кода и рабочего дерева. Не включай чужие или временные изменения в
свои коммиты.

Сначала проверяй масштабируемость по `rules/scalability.md`. Если решение
требует индивидуальной доработки под каждого продавца, его нельзя внедрять.

Ключи API, токены и персональные данные не должны попадать в код, документы,
логи или ответы. Любая информация продавца изолируется на серверной стороне.

Для интерфейсов Argus используй полноширинные рабочие таблицы, ясные статусы
на языке пользователя и моноширинное выравнивание чисел там, где их сравнивают
по столбцам.
