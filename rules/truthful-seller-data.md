# Достоверность данных продавца

- Нельзя показывать продавцу расчётное, косвенное или тестовое значение как
  подтверждённый факт.
- Заказы WB сами по себе не подтверждают, что склад начал физическую сборку.
- Пока работник не подтвердил отбор товара из ячейки, показатель «В сборке»
  равен нулю и не рассчитывается из очереди заказов WB.
- После подтверждённого отбора «В сборке» равно фактически отобранному, но ещё
  не отгруженному количеству. «Доступно к продаже» равно общему остатку за
  вычетом только этого количества.
- Менять этот контракт можно только после появления проверенного источника
  статуса сборки и сквозного теста на отдельном контуре.
