# Достоверность данных продавца

- Нельзя показывать продавцу расчётное, косвенное или тестовое значение как
  подтверждённый факт.
- Четыре числа продавца (решение владельца 17.09.2026):
  «Всего товара» — последнее количество из учёта склада;
  «Заказано» — куплено на площадке, поставки ещё нет;
  «В сборке» — заказ передан складу поставкой или по нему уже отбирали товар;
  «Доступно к продаже» = «Всего» − «Заказано» − «В сборке».
- Один заказ считается ровно один раз: он либо «заказан», либо «в сборке».
  Доступное уменьшается один раз — в момент покупки на площадке, потому что
  товар обещан покупателю.
- «В сборке» не выдумывается из статусов площадки: это либо поставка, которую
  склад получил в Аргусе, либо записанный отбор из ячейки.
- Обещать больше, чем есть в учёте, нельзя: сумма «заказано» и «в сборке»
  обрезается по остатку, доступное не уходит в минус.
- Отгрузка уменьшает «Всего» только после того, как склад проведёт реализацию
  в 1С и придёт следующий обмен. Пока это так, разрыв между отгрузкой и
  обменом остаётся известной слабостью: закрывается переводом «Всего» на
  ячейки Аргуса.
- Менять этот контракт можно только вместе со сквозным тестом на отдельном
  контуре (`test/seller-stock-e2e.js`).
