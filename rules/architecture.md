# Архитектура

- Фронтенд остаётся статичным: HTML, CSS и vanilla JavaScript без сборки.
- API и бизнес-правила находятся в отдельном `argus-api`; не дублировать
  авторизацию, изоляцию продавцов и формулы остатков только в браузере.
- 1С на текущем этапе является источником данных. Любая обратная запись или
  изменение модуля 1С требует отдельной задачи.
- Статусы заказов и формула доступного остатка вычисляются единообразно на
  сервере и используются одинаково в экране и выгрузках.
- Агенты формируют рекомендации и задания. Операции с остатками, доступами,
  ключами и деньгами подтверждаются человеком.
- Везде, где человек выбирает товары из списка (приход, привоз продавца,
  поставка, перенос, любая будущая выборка), — панель выбора, как у
  виртуального склада: поиск, галочки, протягивание левой кнопкой мыши,
  количество у строки, выбор сохраняется между страницами и при поиске,
  загрузка Excel с явным выбором листа и столбцов, строки узнаёт сервер
  по каталогу этого продавца (`POST /api/products/match`). Ручные строки
  «вписать товар и количество» не делать (владелец 06.10.2026). Готовая
  панель — `product-picker.js` (`ArgusProductPicker.open`); перенос в
  виртуальный склад — `virtual-warehouse-stock.js`, вид у обеих общий.
