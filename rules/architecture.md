# Архитектура

- Фронтенд остаётся статичным: HTML, CSS и vanilla JavaScript без сборки.
- API и бизнес-правила находятся в отдельном `argus-api`; не дублировать
  авторизацию, изоляцию продавцов и формулы остатков только в браузере.
- 1С на текущем этапе является источником данных. Любая обратная запись или
  изменение модуля 1С требует отдельной задачи.
- Статусы заказов и формула доступного остатка вычисляются единообразно на
  сервере и используются одинаково в экране и выгрузках.
- Агенты формируют рекомендации и задания. Операции с остатками, доступами,
  ключами и деньгами подтверждаются человеком.
