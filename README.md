# argus-product

Продукт «Аргус» — SaaS для владельцев fulfillment-центров (склады, обслуживающие
продавцов Wildberries/Ozon). Идея: команда ИИ-агентов вместо найма складских
менеджеров, расхождение по количеству ловится в момент приёмки, а не через месяц
на инвентаризации.

Статичные HTML-страницы, без сборки и фреймворков — каждый файл открывается
как есть, переходы обычными `<a href>`. Бэкенд — отдельный репозиторий
[argus-api](https://github.com/tatarinov0909-sudo/argus-api), фронтенд ходит
в `https://api.argus-ai.online`. Лендинг (маркетинговая страница, отдельная
палитра, без входа) — отдельный репозиторий
[argus-landing](https://github.com/tatarinov0909-sudo/argus-landing).

## Страницы

| Файл | Что это | Кто заходит |
|---|---|---|
| `index.html` | Вход / регистрация, выбор роли | все |
| `cabinet_main.html` + `cabinet_main.js` | Кабинет владельца склада | платящий клиент |
| `loader.html` | Мобильный экран работника склада — приёмка и отгрузка | сотрудник склада |
| `client_access.html` | Акты приёмки для продавца | клиент склада |
| `fonts.css` + `fonts/` | Самохостящиеся Inter и IBM Plex Mono | — |

## Деплой

Обычный FTP на reg.ru, документ-рут `/www/argus-ai.online/`. После любой
правки — залить файл(ы) заново тем же способом, вручную владелец сайт не
трогает.

## `docs/`

Хендофф-документы и старые постановочные промпты — история решений, не
исполняемый код.
