Расскажите, как устроен ваш склад
Опишите ряды, стеллажи и ярусы — Аргус построит карту и начнёт подсказывать работникам, куда класть товар. Поправить размеры можно в любой момент.
Соберите склад
Нажимайте плюсы прямо на схеме: между рядами — проход, справа — новый ряд. Нажмите на сам ряд, чтобы задать стеллажи и ярусы, на букву над ним — чтобы переименовать.
⚠ Изменение размеров пересобирает склад заново — все текущие объединения ячеек будут сброшены.

Инвентаризация
Всё, что Аргус вам говорит, стоит на цифрах, которые кто-то однажды ввёл. Пересчёт — единственный способ проверить, что база и полка всё ещё говорят об одном.

Назначить пересчёт
Работник не начинает пересчёт сам — он видит только те ячейки, которые вы назначили. Аргус выбирает их правилом: сначала те, где расхождение вероятнее.
Как часто считать
Счёт отнимает смену у сборки, поэтому пересчёт должен быть редким. Слишком частый перестают делать честно.

Площадки
Аргус сам забирает сборочные задания с маркетплейса и заводит их заказами склада. В кабинете продавца при этом не меняется ничего: Аргус только читает.
Загрузка…
—
Подключить продавца
Нужен только ключ API продавца и его согласие. Ключ сохраняется зашифрованным и обратно не показывается никому — ни здесь, ни продавцу.
Аргус спрашивает у площадки только сборочные задания и список складов продавца. Карточки, цены, реклама и аналитика не читаются. Изменить на площадке Аргус не может ничего — такой возможности в нём просто нет.
Не подключено
Остатки и номенклатура пока не синхронизируются автоматически
Если в 1С уже настроено адресное хранение
Аргус прочитает справочник ячеек напрямую и сам построит карту склада — конструктор не понадобится.
Если адресного хранения нет
1С понадобится только для остатков и номенклатуры. Структуру склада вы уже собрали вручную в конструкторе.
Прямого открытого API у большинства версий 1С нет, поэтому подключение идёт не по ключу API, а через небольшой файл-модуль (внешнюю обработку), который устанавливается один раз.
1
Скачайте модуль для 1С
Файл внешней обработки — передайте его тому, у кого есть доступ к вашей базе 1С.
2
Установите его в 1С
Файл → Открыть → выбрать скачанный файл. Стандартная процедура, прав администратора на сервере не требует.
3
Введите код активации в модуле
Этот код привязывает вашу базу 1С именно к этому кабинету Аргус — никто другой с его помощью подключиться не сможет.
ARG-7734-1C Скопировать
4
Готово
Модуль сам будет присылать остатки по расписанию. Дальше ничего делать не нужно.
