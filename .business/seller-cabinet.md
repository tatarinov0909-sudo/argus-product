# Кабинет продавца

Кабинет только для чтения. Главный экран — остаток с тремя числами: «На
складе», «В заказах», «Доступно к продаже». Последнее число является главным
для решения продавца.

Кабинет также включает заказы со статусами, движения, акты приёмки, историю
товара и две выгрузки: Excel для просмотра и специальный файл для импорта
остатков в 1С продавца по штрихкоду.

Полная утверждённая спецификация: `../docs/Спецификация кабинета продавца.md`.
